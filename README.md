# Windows Backup Scheduler

Windows-приложение для автоматического копирования файлов и папок по расписанию.

## Назначение

По описанию проекта приложение позволяет выбрать файлы и папки, настроить расписание копирования и запускать программу вместе с Windows с размещением в системном трее.

## Что опубликовано

В репозитории находится готовая сборка [App_Back.exe](App_Back.exe). Исходный проект и инструкция сборки пока не опубликованы.

Поэтому этот репозиторий представляет готовую программу; оценить реализацию по исходному коду здесь пока нельзя.

## Использование

Скачайте сборку на компьютер с Windows и настройте пути и расписание в интерфейсе приложения. При необходимости добавьте программу в автозагрузку Windows.

Работу программы следует сначала проверить на тестовых папках, чтобы убедиться, что выбранные пути и расписание соответствуют задаче.
